# Dynamic Data Display Grid

## 📌 Project Overview

The **Dynamic Data Display Grid** is a responsive web application developed using **HTML, CSS, and JavaScript**.

The project fetches user information dynamically from the **JSONPlaceholder REST API** and displays the data in an attractive card-based grid.

Users can search for people by name, sort the results alphabetically, and filter users based on their city.

## 🚀 Features

* Fetches user data from a REST API
* Displays users in responsive cards
* Search users by name
* Sort users from A-Z
* Sort users from Z-A
* Filter users by city
* Displays username, email, phone, website, city, and company
* Loading status while data is being fetched
* Error message if API data cannot be loaded
* Responsive grid layout
* Hover animation on user cards

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and responsive grid layout
* **JavaScript** – API integration, filtering, searching, and sorting
* **JSONPlaceholder API** – Source of user data

## 🔗 API Used

The project uses the JSONPlaceholder Users API:

`https://jsonplaceholder.typicode.com/users`

## 🔍 How It Works

When the webpage loads, JavaScript sends a request to the JSONPlaceholder API.

The received user data is stored in an array and displayed dynamically as cards.

The user can then:

1. Enter a name in the search box.
2. Select **A-Z** or **Z-A** to sort users.
3. Select a city to filter users.
4. Combine search and city filtering.

## 📸 Project Output
